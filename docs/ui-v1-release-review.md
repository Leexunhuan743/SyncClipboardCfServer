## 架构与实现

| 方面 | 当前判断 | 证据与边界 |
|---|---|---|
| 模块划分 | 适合零构建、原生 ES 模块的规模 | `api.js` 收 HTTP/归一化，`filters.js` 收 URL 状态，`signalr.js` 收推送；组件不直接发请求。`main.js` 是装配点。`main.js` 与 `list.js` 已很长，但单凭行数不构成发布缺陷；继续扩功能时应先缩小动作与状态耦合。 |
| 状态与异步 | 关键竞态已有明确所有权 | `store.js` 不提供订阅，动作后显式渲染；列表、统计、概览、活动、轮询和预览各用 latest gate。这个设计可读，但每新增状态出口都要检查所有渲染路径。首屏会话失败、深链接迟到、跨视图选区等漏口已在 §171 修复（§176 逐条实测）。 |
| 写操作一致性 | 依赖服务端版本冲突保护，前端要使用最新条目 | 单条/批量写共用 UI API；批量按 100 条分片，报告部分失败与已生效数。§173 修复行内动作抓构建期快照的问题：按钮点击时现读 `ref.item`，否则收藏后再复制会以旧版本触发 409，访问时间不更新（§176 实测 3 次 PATCH 全 200 且 `lastAccessed` 推进）。 |
| 资源与安全边界 | 静态审查未发现阻断缺陷 | 用户内容使用 `textContent`，单条路径编码，下载名安全化；会话 Cookie、同源来源校验与 CSP 在服务端/`_headers`。这只是代码证据，不替代实际部署环境检查。 |
| 响应式与无障碍 | 主要路径已实测 | 原生 `<dialog>`、焦点交接、字段级错误、键盘帮助、粗指针 44px 命中区。三档探针覆盖 1440×900、390×844、1024×768 coarse，读数与文档同值（表格行 47 / 表格+粗指针 61 / 卡片 103 / 带徽标卡片 131）。真机触屏与 6× CPU 降速未覆盖。 |

## 功能覆盖与缺口

| 用户任务 | 代码现状 | 发布判断 |
|---|---|---|
| 登录、会话失效、登出 | 会话探测失败可重试；401 回登录；登出失败留在当前页说明原因 | 核心路径齐；两类失败态已在 §176 实测（拦掉会话请求 / 拦掉登出请求） |
| 浏览历史 | 搜索、类型/收藏/日期/回收站筛选，六字段单键排序，分页，URL 状态与后退 | 核心路径齐；「清除筛选」同时重置排序和页大小沿用 D19，若要改变需单独产品定案 |
| 使用记录 | 全文/图片预览、复制、原文件或文本下载、访问时间更新 | 核心路径齐；短文本字符数口径已统一（§175），emoji 与大文本两条路径在 §176 实测 |
| 编辑与管理 | 文本编辑保存为新记录；收藏、置顶、软删/恢复/彻底删除、批量操作与部分失败提示 | 核心路径齐；编辑**不修改原记录或当前剪贴板**，是 ADR D30 的明确语义；「未改一字点保存」会静默退出编辑（有意不建记录），**无提示**这一点已登记、未改（§176.4） |
| 状态与维护 | 推送加轮询兜底、统计/活动、部署信息、保留策略与完整性检查 | 功能齐；统计每次读取仍遍历 R2 的 `history/` 对象。Group 只存一份 ZIP，并不会按压缩包条目增加对象数；但默认 1000 条仅限制活跃记录，回收站与孤儿对象仍可累积。大库的子请求与响应时间尚未量化 |
| 可选效率功能 | 列显示开关、多键排序、批量下载均无入口 | 作为已登记的产品边界，而非现有动作失效；正式版若承诺这些能力，发布文案必须先收窄或补实现 |

## 本轮确认并处理的缺陷

1. Shift 范围选择原用建行时下标，重排/删行后可能选错记录；现按记录 key 和当前顺序计算（§171，§176 实测）。
2. 首屏会话请求失败原会留下永久骨架；现进入可重试错误态（§171，§176 实测）。
3. 预览保存中 Esc/取消可退出编辑、确认框对不可中止写操作展示「中止」、登出失败假装成功，
   以及远端列表已变而统计未刷新；均已按调用链修正（§171，§176 实测前三项）。
4. 行内动作持有旧 `version` 导致收藏后复制的访问时间 PATCH 409；现改为读取 `ref.item`（§173，§176 实测）。
5. 表格档 + 粗指针骨架 47px 与真实行 61px 不等、焦点被吸顶链遮住；对应 CSS 已改（§172、§173，
   §176 在 1024×768 coarse 档复测 `SKELETON gap=0`、`occlusion 166 ≥ 162`）。
6. 预览头部、保存与复制提示对 emoji 的字符数口径不一致；短文本统一用 `charCount()`，
   大文本省略数字以避免同步扫描 1 MiB 正文（ADR D39，§175，§176 实测三处一致）。
