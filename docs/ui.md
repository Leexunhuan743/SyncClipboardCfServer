# Web 界面

> 界面只有一套，挂在 `/ui/`。本文是唯一 UI 权威文档：只写当前边界、交互不变式、安全和验证方法。
> 历史缺陷与迭代过程留在 Git 历史。

## 1. 架构边界

| 面 | 路径 | 说明 |
|---|---|---|
| 官方协议 | `/api/*`、`/SyncClipboard.json`、`/file/*`、`/SyncClipboardHub` | 官方客户端依赖，不为 UI 改协议 |
| UI API | `/ui/api/*` | 浏览器专用，可有不同分页/排序/批量语义；实现在 `src/ui/` |
| 界面 | `/ui/` | TypeScript 单页应用（构建产物在 `public/ui/`） |

`UI_ENABLED=false` 时 `/ui/` 的所有静态资源与 `/ui/api/*` 都 404；协议面不受影响。

### 源码与构建

```
web/
├── index.html           入口模板（%APP_JS% / %APP_CSS% 由构建替换成带内容哈希的路径）
├── build.mjs            esbuild 打包脚本（只用 node 内置模块 + esbuild）
├── static/              原样拷贝：品牌图标、manifest、首帧主题脚本 theme-init.js（同时负责按风格生成标签页图标）
├── tsconfig.json        严格模式，DOM 类型
├── src/
│   ├── main.ts          入口：探测会话 → 登录页 / 应用
│   ├── app.ts           控制器：状态、请求、动作、推送与轮询、快捷键
│   ├── state.ts         应用状态与派生
│   ├── theme.ts         风格 × 明暗；切换时同步 theme-color 与标签页图标
│   ├── lib/             纯逻辑与基础设施（api / query / filters / format / push / frames / clipboard / dom / icons / types）
│   ├── ui/              toast、模态框、弹出菜单、快捷键注册表
│   ├── views/           登录、侧栏、顶栏、概览、记录流、详情、批量条、分页、部署信息、新建
│   └── styles/          tokens / base / components / shell / feed / login，由 app.css 统一 @import
└── test/                lib 纯逻辑的单元测试（vitest）
```

- **构建**：`node web/build.mjs` 把 `web/` 打包到 `public/ui/`（已在 `.gitignore`）。`wrangler.toml` 的 `[build]` 钩子让 `wrangler dev` 与 `wrangler deploy` 都先跑它；本地改源码用 `npm run dev:web` 监听重建。
- **哈希与缓存**：`/ui/assets/*` 文件名带内容哈希，长缓存 `immutable`；入口 HTML、`theme-init.js` 每次重验证（见 `public/_headers`）。
- **无运行时依赖**：浏览器拿到的是纯静态文件；没有框架，视图是 `render(state)` 形状的函数，列表按 key 对账。
- **类型**：`npm run typecheck` 同时检查 `src/`、`test/` 与 `web/`（两份 tsconfig：服务端 workers 类型 / 前端 DOM 类型）。纯逻辑模块（`query.ts`、`filters.ts`、`format.ts`、`frames.ts`、`pagination.ts`）不依赖 DOM，因此能在 Node 下直接单测。

## 2. 信息架构

- **侧栏**：视图导航（全部 / 文本 / 图片 / 文件 / 组合 · 收藏 · 回收站，带计数）、同步通道状态（旁边写「最近同步 N 分钟前」）、部署信息、快捷键、主题、账户。窄屏是抽屉。
- **顶栏**：搜索（`/` 聚焦；命中处在卡片里高亮）、时间范围、排序、密度（舒适/紧凑）、刷新、**复制最近一条 / 粘贴剪贴板内容**两个图标按钮、新建（菜单：新建文本 / 上传文件或图片 / 粘贴剪贴板内容 / 复制最近一条）。手机上（≤700px）顶栏向下滚动时收起、向上滚动时恢复。
- **手机底部标签栏**（≤860px）：记录 / 收藏 / 回收站 / 更多（更多 = 打开侧栏抽屉，里面有按类型的完整导航与设置）。
- **概览条**：记录 / 收藏 / 存储三个真实数字 + 近 14 天新增柱状图；下方是需要处理的健康提示（连接中断、时钟差 > 5 分钟、上轮清理失败）。
- **卡片动作**：复制（非文本/图片是下载）、收藏、置顶、移到回收站四个图标按钮，没有「更多」菜单 —— 查看详情就是点卡片（或 `Enter`），其余动作都已直接摆出。
- **收藏夹**：侧栏「收藏夹」区列出用户自定义名字的收藏夹（带条数）和「新建收藏夹」。放进收藏夹的记录**不会被自动清理**；一条记录只能放进一个收藏夹，独立于星标。入口：详情底部的「收藏夹」按钮（在某个收藏夹里时按钮上写它的名字）、多选后批量条的「放入收藏夹」，菜单里可选收藏夹 / 移出 / 新建并放入。收藏夹视图（`?folder=<id>`）的列表头有「重命名」「删除收藏夹」。
- **记录流**：按日分组（仅按时间排序时）的记录卡；列表头有全选、计数、清除筛选；收藏与回收站视图里可再叠加类型筛选。
- **详情面板**：宽屏并排在右侧（不遮挡列表）；≤1180px 是右侧浮层；窄屏全屏。包含全文阅读器 / 图片查看 / 文本文件预览 / 文件信息、元数据与动作；整段文本恰好是 http(s) 链接时多一个「打开链接」。标题栏有「上一条 / 下一条」箭头，不必关面板再点下一张卡；元数据是两列（标签在上、值在下，文件名与哈希占整行）；底部两行动作用同一套等分栅格（主要动作一行、收藏 / 置顶 / 回收站一行），左右边缘对齐。详情是浮层 / 全屏（≤1180px）时，所有动作的最上面多一行单独的「关闭」按钮：手机上右上角的关闭键单手够不着，大拇指够得到的底部也要能关；宽屏并排面板不显示它。**详情里只有一条滚动条**：文本框 / 图片查看器占「面板高度 − 元数据」，自己在内部滚动，长文本不会再撑出外层滚动条（外层 overflow 只是屏幕矮到放不下时的兜底）；实现上必须给这些 flex 子项显式 `min-height: 0`，否则自动最小高度 = 内容完整高度，缩不下来。
- **添加记录的三个入口**：新建文本（`n`，也可直接在页面上 `Ctrl/⌘+V` 粘贴文字，会打开预填好的新建框）、上传文件或图片（`u`、选择器、拖拽到页面、粘贴截图/文件）。上传走 `POST /ui/api/upload`，与官方客户端读到的是同一种记录。
- **首次使用**：库是空的时候，空状态里直接给出「客户端该填的服务器地址」与复制按钮。
- **部署信息**：服务器地址（客户端该填什么）、同步健康、存储、保留策略（在线可改）、数据完整性自检、清空回收站 / 全部。

## 3. 交互不变式

> 这里不保存“为什么当时改过”，只保留当前规则。

1. **action 返回结果，视图呈现结果。** 请求发出不等于成功；成功态只由真实结果驱动（按钮就地变对勾 1.4 秒，toast 只补充说明）。
2. **异步视图都有竞态守卫。** 列表请求带 ticket + `AbortController`，迟到的响应不能覆盖新状态，被取代的请求不算失败；详情里的全文/图片同理。
3. **同一视图刷新按 key 对账。** 内容签名没变的卡片原样复用，避免缩略图重载、焦点丢失；轮询每 10 秒就会触发一次渲染。
4. **推送是轮询的加速器，不是替代品。** WS 在线时轮询退为 2 分钟一次的看门狗；失联回 10 秒；**页面隐藏时断开推送且完全不轮询**，切回可见时立刻补查一次（后台标签页没人看，轮询只是白花 Worker 请求与 D1 读）。连续失败 5 次后冷却 10 分钟再试。
5. **软删不确认，给「撤销」。** “移到回收站”可逆，用 toast 里的撤销代替确认框；**彻底删除**与**清空**不可逆，必须确认（清空全部还要逐字输入「清空」）。
6. **删除/恢复后焦点交接。** 行立即消失，键盘焦点移到同一位置的下一张卡片，不掉回 `<body>`。
7. **改变结果集成员资格的筛选变化必须清空选择集**（类型/收藏/回收站/搜索/范围）；排序、翻页、页大小不属于成员资格变化。
8. **筛选状态进 URL**（`?type=&q=&starred=1&trash=1&range=&sort=&order=&size=&page=`），只写与默认值不同的项；记录深链接是 `#Type-hash`。预设时间范围不写边界进 URL，每次请求按“现在”重算。
9. **动作读当前 item。** 动作分派时从 `state.items` 读最新的那一份，不用构建时的闭包快照；收藏/置顶的目标值取按下那一刻的最新数据（连点两次必须反向）。
10. **列表正文被服务端截断到 500 字符。** 复制、编辑、批量复制都必须先取完整正文，复制走截断值就是把内容砍一半。
11. **文本编辑保存为新记录。** 正文一改 hash 就变；保存成功后详情切到新记录，失败时保留输入；正文 > 1 MiB 不开放编辑（点「编辑」直接说明原因并建议下载后本地编辑，而不是打开一个卡顿的巨型输入框）；全文还没取回时不开放编辑。
12. **长批量可中止，但写操作只在批次边界停。** 已生效数量如实报告（`api.batchUpdate` 的 signal 只当停止旗子，不掐断在途那一片）；读批量可连在途请求一起取消。
13. **复制/下载成功后推进 `LastAccessed`**，但回显 `version` 与 `lastModified`，一次“读取”不制造版本变化。
14. **统计归属与当前视图一致。** 侧栏计数用活跃口径，回收站计数用 `deletedCount`；类型筛选 chip 的计数随视图走。
15. **快捷键只是加速器。** 每个键位都有可见等价入口；帮助表与派发器出自同一份注册表（`ui/shortcuts.ts`）；输入框里、模态框/菜单打开时不抢键。注册表是**整张替换**的、派发器全局只装一次，应用停止时清空 —— 会话过期后重新登录，按键必须作用在新的应用上，而不是命中已销毁的旧应用的闭包。
16. **键盘可达。** Tab/方向键/Enter/Space 能完成搜索、列表动作、分页、详情、批量与对话框；`j/k` 移动（详情打开时是「翻看」：直接换成相邻那条的内容）、`Enter` 打开、`x` 选择、`Ctrl/⌘+A` 全选本页、`Esc` 逐级关闭。
17. **浮层进顶层。** toast 与菜单是 popover（顶层），模态框打开时仍在它上面；只保留一套 toast。
18. **粗指针命中区 ≥ 44px；hover 动作只是增强。** 触屏上卡片操作常驻；信息不能只靠颜色或 hover（星标/置顶是填充 vs 描边 + 文字标记）。
19. **表单错误挂到字段。** 只有字段自身不合法才设 `aria-invalid` 并用 `aria-describedby` 关联；网络/500 不能冒充字段错误。
20. **回收站固定出口：恢复、查看、彻底删除。** 彻底删除只作用于 `IsDeleted != 0` 的记录（判据在服务端 SQL 里）。
21. **上传一条路径，三个入口。** 选择器、拖拽、粘贴都进 `uploadFiles`：先在前端按 `info.limits.maxUploadBytes` 拦下空文件/超限文件，逐个上传（可取消），完成后回到最新、单个文件时直接打开详情；失败的文件逐个说明原因，不影响其余。
22. **后台刷新带来的新记录不悄悄顶列表。** 用户已滚离顶部（>240px）时，同一查询的相邻结果里多出来的记录累计成「↑ N 条新记录」，点击回到顶部；回到顶部自动清零。
23. **手机上详情占一格历史。** 窄屏（≤1180px）打开详情 `pushState`，系统返回键/侧滑返回就是"关闭详情"而不是"退出页面"；宽屏并排显示，不压栈。会改变结果集的筛选变化不弹历史（紧接着要写入新的一格）。
24. **手机适配的底线。** 底部标签栏与批量条、提示条、列表尾部互相让开并避开安全区；粗指针下输入框字号 ≥16px（防 iOS 聚焦放大）；对话框在 ≤600px 是贴底的全宽抽屉。
25. **搜索命中必须看得见。** 命中词高亮（`<mark>`，用户内容仍只经 textContent）；命中位置很靠后时卡片从命中前几十个字符处截取并加省略号。
26. **会话过期要说原因。** 任何请求 401 回到登录页，并显示「登录已过期，请重新登录」；主动退出不显示。
27. **多选有四个入口，进入后整页换成勾选。** 点图标块、悬停出现的勾选框、Ctrl/⌘+点击（Shift+点击选范围）、触屏长按（450ms，振动一下）；Ctrl/⌘+A 全选本页（输入框里仍是全选文字）。选中至少一条后，每张卡的图标块换成勾选框，列表头显示「已选 N 项」与「取消选择」，底部出现批量条（手机上只留图标但保留数量）。长按触发之后紧随的那次 click 不当成"打开详情"；触屏上卡片文字不可划选（避免长按选字抢手势，复制有专门的按钮）。
28. **紧凑密度要整齐。** 桌面每条一行，类型 / 大小 / 时间 / 标记（置顶、星标、长文本…）各占**固定宽度的一列**，有没有星标都不会让整行左右错位，操作悬停时浮在最右侧（不占位）；手机是「一行正文 + 一行信息」，右侧只留复制（或下载）与移到回收站两个按钮，收藏 / 置顶在详情和长按多选后的批量条里。探针检查右缘一致与操作不溢出。
29. **带鱼屏上内容要铺开，不留窄带。** 内容区上限 3200px；记录卡的列数由**滚动区此刻的宽度**（CSS container query，而不是视口）决定：舒适密度 1 / 2（≥1280）/ 3（≥1900）/ 4（≥2500）/ 5（≥3100）列，紧凑密度 1 / 2（≥1500）/ 3（≥2300）/ 4（≥3000）列；详情面板宽度 `clamp(468px, 25vw, 760px)`；概览在滚动区 ≥1500px 时多出「回收站」与「类型构成」两张。打开详情面板会让滚动区变窄，列数自动回落。
30. **部署信息先给结论，再给细节。** 顶部状态总览一眼说"运行正常 / N 项需要关注"（时钟差 > 5 分钟、上轮清理失败算需要关注；推送未连接、清理还没跑过只是提示）；下面是卡片网格：窄屏 1 栏、桌面 2 栏、带鱼屏 3 栏（对话框宽度随之放到 1560px）。多栏是按 DOM 顺序依次填的，三栏时「存储 + 保留策略」会一起落进中间列、右列只剩两张矮卡，所以三栏宽度（视口 ≥1900px，与 `feed.css` 的 `column-count: 3` 同一断点）下用 `matchMedia` 把保留策略挪到最后，中间列是「存储 + 数据维护 + 危险操作」、右列是保留策略，三列高度接近；窗口宽度在打开期间跨过断点时顺序会跟着变，窄屏顺序不变。包含"客户端该怎么填"的三步说明、同步健康（含下一次清理的倒计时）、存储构成条、保留策略（数字输入 + 预设 + 人话换算，如 43200 分钟 = 30 天）、数据维护与危险操作。
31. **主题 = 风格 × 明暗，四套风格可随时切换。** 默认（冷灰蓝，浅/深/跟随系统）、海岸暮色（深海军蓝夜空 + 橙色落日，胶囊圆角、网点）、暖纸田园（米黄纸 + 铁锈橙/鼠尾草绿，无描边大圆角、纸纹、层叠山丘）、网点俱乐部（米白 + 深蓝 + 朱红双色，粗描边、红色硬偏移阴影、半调网点、对位十字）。入口：侧栏调色盘按钮 / 快捷键 `t` / 登录页底部的风格小圆点；选择即时生效并记在本机（`clip-style`），首帧由 `theme-init.js` 同步写好，不闪默认风格。三套特色风格自带固定明暗（海岸暮色是深色，另两套是纸色），所以明暗开关只对默认风格可用。**标签页图标也随风格 / 明暗变**：每套风格的图标呼应它自己的品牌标记（默认=靛蓝圆角方块，深色为浅靛蓝；海岸暮色=橙色落日；暖纸田园=铁锈橙大圆角；网点俱乐部=深蓝方块加朱红偏移阴影）。图标由 `theme-init.js` 生成（首帧同步写 SVG，随后栅格化成 PNG 给不支持 SVG 图标的浏览器）；每次切换都**删掉旧的 `<link rel=icon>` 再新建一个**，始终只留一个，因为多个 icon 并存时浏览器不一定响应 `href` 的改动。添加到主屏幕用的图标是固定的。
32. **每套风格必须成套且可读。** 风格 = 一整套颜色令牌（必须覆盖默认风格的全部颜色令牌）+ 造型覆盖 + 纯 CSS 装饰（内联 SVG / 渐变）；`test/ui-guard.test.ts` 守着：令牌成套、风格表三处一致（`theme.ts` / `theme-init.js` / `themes.css`）、每个"文字 × 底色"组合对比度 ≥ 4.5:1（默认浅色、默认深色与三套风格都查）。
33. **选择前后列表不动。** 列表头高度固定（桌面 52px、粗指针 60px），「取消选择」出现不会把下面顶下去；探针在桌面与手机上各量一次。
34. **正在输入的搜索词不被后台刷新覆盖。** 防抖等待期间（已输入、未提交）渲染不改写输入框。
35. **概览分「完整」与「轻量」。** 完整概览会让服务端列举整个 R2 桶（收费的 Class A 操作）来算存储体积；日常刷新（收藏、移到回收站、轮询发现变化…）走 `?storage=0` 的轻量概览，只取计数，存储体积沿用上一次的值。只在这几种情况取完整的：第一次、距上次完整取已超过 10 分钟、上传 / 彻底删除 / 清空之后、用户主动刷新（点按钮或 `r`）。部署信息对话框读的是 `/ui/api/info`（总是完整）。
36. **风格的阴影要留出位置。** 硬偏移 / 光晕阴影会超出元素盒子，而带 `overflow` 的祖先（可滚动的侧栏导航、会换行的 chips、对话框正文）会把它切成一刀。这类容器必须给阴影留出内边距，**悬停态也要算**：网点俱乐部的按钮悬停时会上移 1px 并把阴影加大到 4px，容器要给上、左留 ≥1px、右、下留 ≥3px（`themes.css` 里的 `.nav`、`.chips`；批量条的 `.batch__actions`），一律用内边距 + 等量负外边距，布局尺寸不变；新增带阴影的风格或组件后跑 `node test/manual/shadow-clip.mjs`。
37. **记录离开当前列表时，详情照样同步。** 例如在「收藏」视图里从详情取消收藏：记录会从列表里消失，但详情面板仍要更新到最新状态（星标变空心），不能因为按列表查不到它就停在旧状态。
38. **收藏夹是界面独有的整理功能，保护靠服务端、不靠客户端。** ① 放进收藏夹的记录不参与自动清理（`FolderId != 0`，豁免条件与收藏/置顶写在同一处 SQL：`src/db.ts` 的 `softDeleteOldest` 与字节估算两条）；② 它独立于星标，官方客户端写 `starred=false` 或重传同一条记录都改不了它（`FolderId` 不进协议 DTO 与整行覆盖写）；③ 放进 / 移出不改 `Version` / `LastModified`（不是内容变更，不触发别的设备同步）；④ 删除收藏夹只把成员移出（先移出再删，不留悬空 id），记录本身不删，且删除前必须确认并写明条数；⑤ 名字 ≤30 个字符（按码点）、唯一、最多 50 个，重名在对话框里就地提示而不关闭；⑥ 「清空全部」会连收藏夹里的记录一并清掉（和星标一样），收藏夹本身保留；回收站里的成员保留 `FolderId`，恢复后仍在原收藏夹。看着的收藏夹被别处删除时，下次刷新提示并回到全部。回归见 `test/folders.test.ts`（进程内，含"去掉豁免条件就必须失败"的判别用例）与 `test/manual/probe-folders.mjs`。
39. **复制最近一条 / 粘贴剪贴板内容是一对镜像入口。** 这个界面最常见的用法是「在一台设备上复制、到另一台上取」：「复制最近一条」把**全库最新**的一条（按创建时间，不受当前筛选 / 排序 / 置顶影响，`pinnedFirst=false`）放进本机剪贴板；「粘贴剪贴板内容」把本机剪贴板存成最新一条。入口：顶栏两个图标、新建菜单、快捷键 `l` / `v`。读剪贴板要安全上下文 + 用户手势 + 浏览器权限，所以结果分三种并各说各的话：不支持（要 https）、被拒（点地址栏权限图标放开，或直接 `Ctrl/⌘+V`）、空（纯空白不存）。文字优先于图片（网页 / 表格里复制常同时带一张渲染图）；图片存成 `剪贴板-<时间>.<扩展名>`；两者都**不弹出详情**（这是快速动作，不该打断当前页面）。回归见 `test/manual/probe-clipboard.mjs`。
40. **同步状态要回答「刚复制的有没有过来」。** 侧栏状态旁写最近一次成功对上账的时间（列表 / 概览 / 轮询任一成功就刷新），悬停给绝对时间；连接中断时它还在，说明数据停在多久以前。
41. **手机顶栏向下滚收起、向上滚 / 回到顶部 / 聚焦搜索时恢复。** 只在 ≤700px 生效，用负外边距让出布局高度（不是盖在内容上）；桌面永不收起。阈值 8px，避免收起后高度变化引起来回抖动。
42. **批量只有一部分生效时不说「失败」。** 服务端逐条判定，没生效的通常只是已被别的设备改过或删掉，其余早已生效；文案写「N 条已…，M 条未生效（通常是…，列表已刷新）」，免得用户整批重做。移到回收站的提示同时说明「所有同步设备上也会消失，30 天内可恢复」。主界面的 429 也翻译成「请在 N 秒后重试」。

## 4. 鉴权与会话

- UI 登录成功后使用 `base64url(payload).base64url(HMAC-SHA256)` 签名 Cookie，payload 为 `{u, exp}`；
- 密钥由 `PASSWORD` 派生，改密码会整体失效旧会话；不建服务端会话表；登出只清本机 Cookie；
- `/ui/api/*` 接受会话 Cookie 或 Basic；官方协议面只接受 Basic；
- UI 状态变更同时校验 `Origin` / `Sec-Fetch-Site`；
- Cookie 的 `Secure` 属性按「用户那一侧是不是 https」判定：请求 URL、`X-Forwarded-Proto`、`CF-Visitor` 任一为 https 即加（经隧道 / 反代访问本地开发服务时，Worker 看到的是回源的 http）；
- 登录页是同一页里的一个状态：`api.session()` 未登录 → 登录页；任何请求返回 401 → 回登录页。

## 5. UI API

完整路由表以 `src/ui/routes.ts`（装配）与 `src/ui/routes/*.ts`、`src/ui/maintenance.ts` 为准；`test/ui-guard.test.ts` 保证**前端调用的每个接口服务端都已注册**。

| 能力 | 当前约束 |
|---|---|
| 历史列表 | `pageSize <= 500`，排序字段白名单，正文截断 500 码点并标记 `textTruncated` |
| 数据读取 | UI 数据端点支持单区间 Range；协议侧不跟随这一偏离 |
| 文本新建 | `POST /ui/api/history`，正文 ≤1 MiB |
| 文件/图片上传 | `POST /ui/api/upload?name=`，请求体是原始字节、`Content-Type: application/octet-stream`（非此类型 415，CSRF 纵深）；上限 = 请求体上限（`info.limits.maxUploadBytes`）；图片扩展名 ⇒ Image，其余 ⇒ File；哈希与协议一致，同名同内容不产生重复记录 |
| 单条更新 | 收藏/置顶/软删/恢复/访问时间 |
| 批量更新 | ≤100 条/批（前端自动分片串行），有界并发，广播在 DO 内逐条保序 |
| 批量元数据 | ≤100 条，可取完整正文 |
| 批量彻底删除 | 只处理回收站记录，并清 R2 数据 |
| 收藏夹 | `POST /ui/api/folders`（新建）、`PATCH /ui/api/folders/:id`（改名）、`DELETE /ui/api/folders/:id`（成员移出后删除）、`POST /ui/api/history/batch-folder`（≤100 条/批，`folderId: null` = 移出）；每个写接口都回最新的收藏夹列表；列表接口 `?folder=<id>` 筛选；收藏夹列表随 `/ui/api/overview` 返回 |
| 保留策略 | 数字=覆盖；`null`=清除覆盖回落 env；缺省=不改；上界 525600 分钟 / 1000000 条（界面按同样的上界提示与拦截） |
| 概览 | `GET /ui/api/overview`；`?storage=0` = 轻量模式，不列举 R2，`info.storage` 与 `stats.totalFileSizeMB` 为 `null`（调用方沿用上一次的值） |

JSON 默认 `Cache-Control: no-store`；数据端点可用 `private, max-age=60` 复用预览字节。

## 6. 回收站语义

软删只置 `IsDeleted=1`，**保留数据文件**，所以图片/文件可恢复。真正释放 R2 空间的出口只有：单条/批量“彻底删除”、“清空回收站”、超过 30 天的硬删清理。“数据不可用”只表示对象确实缺失，不代表记录处于回收站。

## 7. 安全

- 前端不用 `innerHTML` 注入用户内容（`h()` 只经 `textContent` / `setAttribute`），守卫见 `test/ui-guard.test.ts`；
- CSP 集中在 `public/_headers`：`script-src 'self'; style-src 'self'`。因此页面里**没有内联脚本、没有 `style=` 属性**；动态样式只用 CSSOM（`el.style.x = …`）；首帧主题脚本外置为 `/ui/theme-init.js`；
- 附件采用默认-deny 内联白名单：图片（除 SVG）、纯文本/CSV/Markdown、JSON、PDF 可内联，其余下载；HTML/XML 家族额外 CSP sandbox；
- 下载文件名不可信：取 basename、替换非法字符、限长并保留扩展名（`lib/format.ts` 的 `safeFileName`）；
- 浏览器会为同源请求自动携带凭据，因此附件渲染必须按同源 XSS 威胁模型处理。

## 8. 设计与可访问性

- 系统字体，不依赖 Web font（面向国内网络，外部字体 CDN 大概率加载失败）；
- 语义色令牌（`styles/tokens.css`），浅/深/跟随系统三态同构；
- 层级靠「底色 → 卡片 → 浮层」三级，而不是满屏描边；
- `prefers-reduced-motion` 下动画降为 1ms；
- dialog 页眉/页脚固定，正文是唯一可收缩区；用原生 `<dialog>`，焦点陷阱与归还由浏览器负责；
- 键盘入口、focus 恢复、`aria-invalid` / `aria-describedby` 属功能正确性，不是额外打磨。

## 10. 性能预算

- 概览与列表并发，活动趋势图不阻塞首屏；
- 一页最多 500 行，列表正文服务端截断；
- 入口 JS ≈ 110 KB（minify，未压缩）、CSS ≈ 70 KB，均带内容哈希长缓存；
- 日常刷新不列举 R2（轻量概览，见不变式 35）；
- 卡片仅在签名变化时重建；无变化的状态不写 DOM；
- 推送在线时轮询 2 分钟看门狗，失联 10 秒，隐藏页不轮询；
- **D1 读行数是第一预算**（免费额度 500 万行/天，计费口径是扫描的行数）。查询形状由 `test/ui-query-plan.test.ts` 钉住：列表的一页与总数走 `idx_h_user_list`（活跃视图只读活跃行、一页只读一页，回收站再大也不影响）；变更信号 `/ui/api/poll` 与总览的 `marker` 都只有 `lastModified` 一个值（读 1 行，不再 `COUNT(*)`）；总览的四个计数与各收藏夹条数从同一次分组算出，不再各扫一遍表；趋势图的查询只在宽屏（图可见）时发。回归见 `test/manual/probe-polling.mjs`。
