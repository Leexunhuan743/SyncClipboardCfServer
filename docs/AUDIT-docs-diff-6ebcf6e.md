## 6. 方法论（下一轮照这个顺序）

1. **`docs/` 的缺陷形态是"指代"而不是"逻辑"。** 检索式只有一条：
   `grep -n 'ui_v[12]' docs/*.md`，然后**逐行问"这半句在说谁"** ——
   机械替换过的句子，**主语和宾语往往处在两个时代**。
2. **"改了别人的名字"和"改了别人的结论"是两件事。** 快照文档里，**被叙述的对象**用什么名字，
   取决于**那句话写下时**它叫什么。
3. **同一事实的副本数 ≥ 2 时，必须数一遍。** 本轮有一处是三份、两处是两份 —— 三组都是"改了一部分"。
   `AGENTS.md` §1 表末那行（"改文档里写死的数字 / 文件名 ⇒ 全文搜一遍"）是对的，
   而**它管不到"句子里的指代"**，那要靠第 1 条的检索。
4. **别信"本轮已同步"的自述。** 有一处声称四处文档同步更新、实际漏一处；另一处声称把行号改成 X、
   实际那一行当时也不是它。⇒ **"自述已改"必须数一遍实际处数**。
5. **行号仍然是最先腐烂的东西**（这一条在本轮**第二次发作**）：现存的 `文件:行` 里又找到 1 处写错。
   凡是"见本文件 :NNNN"这种**自指行号**，一律换成**小节号 + 引文**。
6. **证据脚本不在，数字就不可复算**：文档里已经出现"引用某个已被清理的脚本的结论"。
   ⇒ 要么把脚本留下，要么把**口径**写进文档（本轮的做法）。
